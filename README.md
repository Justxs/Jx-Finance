# Just-Finance

Self-hosted personal finance tracker built as a React SPA + ASP.NET Core API.

## Prerequisites
- .NET 10 SDK
- Node.js 22+ and pnpm
- Docker Desktop (for Postgres)
- just (task runner)

## Local setup
1. Copy env vars:
	- `cp .env.example .env` (or create `.env` manually on Windows)
2. Install frontend deps:
	- `pnpm --prefix frontend install`
3. Start dev servers:
	- `just dev`
4. Open:
	- API: http://localhost:8080
	- Frontend: http://localhost:5173
	- Scalar docs: http://localhost:8080/scalar/v1

## Codegen
The OpenAPI spec is generated by the API and the frontend client is generated by Orval.

1. Start the API.
2. Run: `just gen`

## Docker stack
`docker compose up -d --build`

Frontend: http://localhost:8081
API: http://localhost:8080

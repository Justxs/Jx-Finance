## Keyboard shortcuts

```mermaid
flowchart TD
    Key["keydown, matched by TanStack Hotkeys"] --> Guard{"Repeat, already handled, in a textbox or combobox,<br/>dialog open, or on /login or /setup?"}
    Guard -->|"yes"| Ignore["ignored"]
    Guard -->|"no"| Which{"Key"}
    Which -->|"n"| New["/transactions?new=true opens the add dialog"]
    Which -->|"/"| Search["click data-shortcut=search, else go to transactions"]
    Which -->|"?"| Help["toggle the help popover"]
    Which -->|"g then a letter within 1.2 s"| Go["d dashboard, t transactions, a accounts, c categories, b budgets,<br/>o goals, l bills, w net worth, r reports, h households"]
```

Below the `md` breakpoint the sidebar becomes a compact header with a scrolling navigation strip, tables become lists (`TransactionsList`) and filters move into a dialog; both layouts share one data source and the switch is CSS only.

# Swedbank CSV import

Back to the [feature walkthrough](<../14. Feature walkthrough with diagrams.md>).

Backend `Imports` (`ImportService`), frontend `imports` (`ImportDataSection`, `ImportDialog`, `ImportSection`). No route of its own; the dialog opens from Settings and Profile.

```mermaid
sequenceDiagram
    actor User
    participant Dlg as ImportDialog
    participant Api as ImportService
    participant Db as PostgreSQL
    User->>Dlg: choose Swedbank, target account, CSV file
    Dlg->>Api: POST /api/import/swedbank/preview
    Api->>Api: validate column order, currency, debit or credit, dates, amounts, references
    Api->>Db: existing references: transactions incl. deleted, TransferImport receipts
    Api-->>Dlg: rows with isDuplicate and looksLikeTransfer
    Dlg->>Dlg: duplicates never selected, suspected transfers start unselected
    Dlg->>Dlg: category recall: exact description and type among the latest 200
    User->>Dlg: per row: income or expense with category,<br/>new transfer with another account,<br/>or match an existing transfer
    Dlg->>Api: POST /api/import/swedbank/confirm, selected rows only
    Api->>Db: begin transaction, advisory lock on the account id
    Api->>Api: matching verifies date, amount and direction
    alt transfer already holds a receipt for this account
        Api-->>Dlg: import.transferAlreadyMatched, nothing written
    else ok
        Api->>Db: transactions, transfers, TransferImport receipts
        Api-->>Dlg: result, link to the imported rows
    end
```

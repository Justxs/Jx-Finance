# Notifications

Back to the [feature walkthrough](<../14. Feature walkthrough with diagrams.md>).

Backend `Notifications` and `RecurringBillReminderJob`, shown by `NotificationBell` in the sidebar foot.

```mermaid
flowchart TD
    Tick["Startup, then every 15 minutes"] --> On{"RecurringBills feature on?"}
    On -->|"no"| Skip["skip"]
    On -->|"yes"| Day["IClock.StartOfDay: start of today in the installation time zone,<br/>safe when midnight is skipped by daylight saving"]
    Day --> LockB["Transaction with advisory lock AppLock.RecurringBillReminders"]
    LockB --> Scan["Active bills of every user with NextDueDate minus reminder days on or before today"]
    Scan --> Dup{"Notification for this bill and local day exists?"}
    Dup -->|"yes"| None["nothing"]
    Dup -->|"no"| Ins["Insert in-app notification with bill name and ISO due date"]
    Ins --> Bell["GET /api/notifications, client localizes the sentence"]
    Bell --> Read["PATCH {id}/read or POST read-all, optimistic"]
    Confirm["Bill confirmed"] --> Read
    None --> Tomorrow["Unconfirmed bill reminds again the next day"]
```

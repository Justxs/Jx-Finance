# Background jobs

Back to the [feature walkthrough](<../14. Feature walkthrough with diagrams.md>).

All four derive from `PeriodicJob`: a `PeriodicTimer` loop, a fresh service scope per pass, an optional feature gate, one pass immediately at startup, failures logged as "{Job} failed.".

```mermaid
flowchart LR
    subgraph PeriodicJob
        direction TB
        R["RecurringBillReminderJob<br/>every 15 min, needs RecurringBills"]
        N["NetWorthSnapshotJob<br/>hourly, needs NetWorth"]
        E["ExchangeRateSyncJob<br/>every 6 h, obeys the auto-sync setting"]
        B["BrokerSyncJob<br/>daily, needs Investments"]
    end
    R --> Notif["Notifications, deduplicated per bill and local day"]
    N --> Snap["Snapshot per active user, failures isolated per user"]
    E --> Rates["Rates from the day after the newest stored rate,<br/>or the last 30 days; prunes ExchangeRateFetchLog"]
    B --> Imp["ImportAsync per enabled connection, failures isolated"]
```

## 2. Gaps inside features that exist

| Feature | Gap | Size |
| --- | --- | --- |
| Investments | No price history; only the last price, so no portfolio value chart except through net worth snapshots | M |
| Investments | Corporate actions other than splits are only counted (mergers, spin-offs, symbol changes) | M |
| Investments | Bonds by hand only; options, futures and short positions out of scope | L |
| Investments | Only Interactive Brokers; no other broker and no generic trade CSV | M |
| Import | Swedbank format only | M per bank, or one generic column mapper |
| Import | No credit-card statements | M |
| Goals | Manual progress only; no link to an account balance and no allocation | S |
| Budgets | Monthly only, no rollover of unspent amounts, no other periods | M |
| Notifications | Bill reminders only, and only while `RecurringBills` is on | S per new kind |
| Recurring bills | Expenses only; no recurring income or recurring transfers | S |
| Households | No global active-household switcher | M |
| Households | Budgets, goals, assets, debts and bills cannot be shared | L |
| Users | No forced password change after an administrator reset (rejected on 2026-09-19 unless done completely) | M |
| Settings | Installation-wide only; no per-user reporting currency, language default or page size | L for currency, S for the rest |
| Exchange rates | ECB only; no manual rate, no currencies outside the ECB list | S |
| Backups | On demand only; a scheduler and offsite copies were removed on 2026-09-05 and stay a deliberate decision | M, needs the decision reopened |

## 4. New ideas

Ordered by how much they would help daily use for the effort.

| Idea | Why | Size |
| --- | --- | --- |
| Budget alerts | A notification at 80% and 100% of a monthly limit reuses the notification table and the reminder job pattern | S |
| Cash-flow forecast | Project the next 30 to 90 days of each account from active recurring bills and recurring income; shows a coming shortfall before it happens | M |
| Saved filters | Name a transaction filter and reopen it; the filter already lives in search params, so a saved filter is a stored query string | S |
| Receipts and attachments | A file per transaction on a volume, included in backups | M |
| Subscription detection | Find expenses that repeat monthly with a similar amount and offer to turn them into a recurring bill | M |
| Transaction templates and duplicate | One click for the entries typed every week | S |
| Audit log | Who changed or deleted what in a shared household account; soft deletion already keeps the rows | M |
| Undo for delete | Rows are soft-deleted, so a toast with Undo and a small trash view are cheap | S |
| Debt amortization | Debts already store an interest rate; add a payment schedule, payoff date and the interest and principal split of each payment | M |
| Goal funding from an account | Tie a goal to an account or a share of it, so progress follows the balance | S |
| Yearly tax summary for investments | Realised gain, dividends and withholding tax per year already exist in the portfolio; a printable page and CSV for the Lithuanian annual declaration | S |
| Dashboard customisation | Choose and order the cards per user | M |
| Report comparisons | This period against the previous one and against the same period last year | S |
| Generic CSV import | The user maps columns once per bank and the mapping is stored; covers SEB, Luminor, Revolut and Wise without code per bank | M |
| Passkeys | WebAuthn as a second factor or instead of the password | M |
| Personal API tokens | Read-only tokens for scripts and spreadsheets | M |
| Data export per user | A member takes their own records out as JSON or CSV without an administrator backup | M |
| Command palette | Search pages, accounts and actions from one shortcut, on top of TanStack Hotkeys | S |

## Suggested order

1. Section 1, because the release is not verified without it.
2. Small gaps that finish existing features: dividends as income, session list, budget alerts, saved filters, undo for delete.
3. Categorization rules together with a generic CSV import; they remove the most manual work.
4. Cash-flow forecast and recurring income.
5. Email, then anything that depends on it.

# Overview

Jx Finance is a self-hosted multi-currency ledger, reporting in EUR by default, for personal finances and small households. It records income, expenses, transfers, assets and debts; it never connects to a bank or moves money.

The core workflow is quick manual entry or a reviewed Swedbank CSV import, followed by balances, budgets and reports. PostgreSQL stores the data. A React SPA talks to an ASP.NET Core API using same-origin authentication with JWTs carried in HttpOnly cookies.

The release includes accounts, categories, split transactions, transfers, imports, budgets, manually updated savings goals, net-worth history, recurring bill reminders, household sharing, reports, CSV/PDF exports and English/Lithuanian UI. See Features for exact boundaries.

The interface is styled as a household ledger: ruled sections instead of boxes, compact navigation, semantic income and expense colors, and bundled Source Serif 4 and Source Sans 3 type. Fonts are served from the application itself, so no externally hosted font request is made. See DESIGN.md.

Installation is private by default: Compose binds published ports to loopback unless the frontend bind address is explicitly changed. Remote usage is intended through a private network with HTTPS.

# Overview

Jx Finance is a self-hosted EUR ledger for personal finances and small households. It records income, expenses, transfers, assets and debts; it never connects to a bank or moves money.

The core workflow is quick manual entry or a reviewed Swedbank CSV import, followed by balances, budgets and reports. PostgreSQL stores the data. A React SPA talks to an ASP.NET Core API using same-origin cookie authentication.

The release includes accounts, categories, split transactions, transfers, imports, budgets, manually updated savings goals, net-worth history, recurring bill reminders, household sharing, reports, CSV/PDF exports and English/Lithuanian UI. See Features for exact boundaries.

The interface uses neutral surfaces, compact navigation, semantic income/expense colors, system fonts and responsive forms. No externally hosted font request is required.

Installation is private by default: Compose binds published ports to loopback unless the frontend bind address is explicitly changed. Remote usage is intended through a private network with HTTPS.

# Decisions

One page per topic. Each page has up to two parts:

- **Current**: the decision as it stands today, in one paragraph per subject.
- **Log**: dated entries, newest first, each naming what was chosen, what was rejected and why. An entry that a later one replaced says so and stays in place.

Before changing behaviour that a page here covers, read that page. When you choose between real alternatives, add a log entry to the topic's page (create a page when no topic fits, and add it to the table below), and update its Current paragraph when the standing decision changes.

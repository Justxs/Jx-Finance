## Domain references

### Swedbank CSV export format
Quoted, comma-separated, UTF-8, header row, account IBAN repeated on every row. Drives the [[6. API surface#Import (v1.2)|importer]].

| # | Column (LT) | Meaning | Used as |
|---|-------------|---------|---------|
| 1 | Sąskaitos Nr. | Account IBAN | match/confirm target account |
| 2 | *(unnamed)* | **Row type**: `10` opening balance · `20` transaction · `82` turnover · `86` closing balance | **keep only `20`** |
| 3 | Data | Date (`YYYY-MM-DD`) | transaction date |
| 4 | Gavėjas | Beneficiary / payee | payee + description |
| 5 | Paaiškinimai | Details / narrative | description |
| 6 | Suma | Amount, **already in account currency** | amount (positive) |
| 7 | Valiuta | Currency (EUR) | — |
| 8 | D/K | **D**ebit / **K**redit | `D` → expense, `K` → income |
| 9 | Įrašo Nr. | Unique entry number | **dedup key** → `Transaction.ImportRef` |
| 10 | Kodas | Entry-type code (AS, K, MK, M, TT, LS, K2…) | optional hinting |
| 11–16 | Įmokos/Dok. Nr., client/payer/recipient codes | references | — |

**Parsing rules**
- Skip the opening-balance, turnover, and closing-balance rows (types `10` / `82` / `86`); import only type `20`.
- `D/K` sets direction; `Suma` stays positive. Foreign purchases are already converted (original amount + `VALIUTOS KURSAS` appear only in the details text).
- Dedup on `Įrašo Nr.` (stored as `ImportRef`) so re-importing the same period is idempotent ([[9. Open questions & decisions|D47]]).
- Flag likely **own-account transfers / cash** (e.g. "Transfer between own accounts", "Withdrawal from Easy Saver", "GRYNIEJI …") so the user can reclassify them as a [[5. Data model#Transfer (v1.1)|Transfer]] instead of an expense.

*Sample (header + one transaction + a skipped balance row):*
```csv
"Sąskaitos Nr.","","Data","Gavėjas","Paaiškinimai","Suma","Valiuta","D/K","Įrašo Nr.",...
"LT47…106","10","2026-05-01","","Likutis pradžiai","653.56","EUR","K","",...      ← skip (opening balance)
"LT47…106","20","2026-05-02","LIDL/50191 …","PIRKINYS … LIDL …","15.77","EUR","D","2026050202154671",...  ← expense
```

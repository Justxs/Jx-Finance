# Current decisions

Updated 2026-09-05. This replaces the outdated draft decision log; Git retains its history.

| Topic | Decision |
| --- | --- |
| Architecture | One API project, feature services use EF directly, thin endpoints, architecture tests |
| Release scope | Finish existing ledger/planning/reporting features; defer tags, ML, FX, investments, offline and wider sharing |
| Money | EUR; decimal/numeric(18,2); canonical strings over HTTP; comma input normalized at the client |
| Authentication | Admin-created users; optional 2FA; absolute 1/30-day sessions; immediate stamp/lockout validation |
| Email | Deferred; no delivered verification, reset or reminder emails; recovery codes and host-side admin recovery are available |
| Sharing | Accounts/Categories only; record owner controls scope; account owner controls archiving; transfer changes require both accounts |
| Member removal | Other owners' account histories disappear even if the removed member entered transactions; personally owned records remain accessible |
| Imports | Duplicate references skipped, including deleted imports; strict Swedbank EUR columns; explicit transfer matching; no automatic money movement |
| Bills | No auto-posting; expected occurrence date required for confirmation; inactive bills reject confirmation; repeats notify once per day |
| Net worth | Includes full balances of all visible accounts plus personal assets minus debts; this is not an ownership-percentage calculation |
| Snapshot schedule | Refresh today's snapshot hourly and on viewing; unique user/date; no invented historical points |
| Design | Neutral surfaces, compact controls, readable typography, semantic colors, mobile navigation; no external fonts |
| Database lifecycle | Apply EF migrations directly on startup; all backup-specific code and logic removed per explicit scope change |
| CI | Gitea Actions configuration already exists, including client drift; no platform-selection question remains |

Deployment choices still belong to the operator: host/private address, hostname/certificate trust and production credentials. Email and advanced features require a later scoped change, not an implied promise in this release.

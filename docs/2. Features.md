# Features and scope

| Area | Current behavior |
| --- | --- |
| Authentication | First-run administrator setup; admin-created users; 1-day absolute session or 30-day remembered session (short-lived JWT access cookie plus rotating refresh cookie); optional authenticator 2FA and recovery codes |
| User management | Create users, change roles, deactivate; update own name/password; new users receive starter categories |
| Accounts | Create/edit/archive accounts; exact computed balances; personal or shared scope |
| Transactions | Create/edit/delete; optional category splits; text/account/category/type/date filters; paginated list |
| Transfers | Dedicated ledger movement, excluded from income/expense; paginated history; accessible-account checks; separate sent and received amounts when the two currencies differ |
| Installation settings | Administrators switch features on and off, choose the reporting currency and the currencies offered, control exchange-rate sync, and set the installation name, default language, time zone, first day of the week, default account and rows per page |
| Multi-currency | Each account has a main currency and can hold balances in any of 30 supported currencies; transactions carry their own currency; in-account currency conversions with an optional fee booked as an expense; ECB reference rates synced daily; totals, budgets and reports expressed in one reporting currency using the rate on each transaction's date |
| Investments | Securities (stocks, ETFs, funds, bonds, crypto, other; bonds by hand only) shared across the installation; buys, sells, dividends, withholding tax, interest, fees and splits on any account; first-in-first-out cost basis, unrealised and realised gain, income by year; last price from the broker or set by hand; Interactive Brokers Flex Query import by file upload or daily through the Flex Web Service, deduplicated by broker id; holdings count toward the account's value, the dashboard total and net worth |
| CSV import | Swedbank format validation in any supported currency, preview, row selection, category selection, explicit transfer creation/matching, duplicate detection including deleted imports |
| Budgets | Create/edit/delete monthly category limits; spending includes split category allocations |
| Goals | Create/edit/delete names, targets, dates and manual progress; no automatic allocation from accounts |
| Net worth | All visible account balances plus personal assets minus personal debts; daily values refreshed hourly and on viewing |
| Recurring bills | Fixed/variable bills; manual confirmation creates one expense for the expected due date; inactive bills cannot be confirmed |
| Notifications | In-app reminders checked every 15 minutes and deduplicated per bill/local day; confirmation marks reminders read |
| Households | Household/member management; Accounts and Categories shareable; transactions follow their account |
| Reports | Custom date ranges, income/expense/net, category breakdown and trends; year presets use the same report |
| Exports | Filtered transaction CSV and PDF |
| UI | English/Lithuanian, light/dark themes, per-browser color palettes, typeface and text size, locale formatting, comma-decimal entry and mobile navigation |

Email verification, password-reset emails and email reminders are deferred. The current release uses administrator-created accounts, recovery codes and an interactive administrator recovery command. An unused email abstraction does not imply email delivery is implemented.

Outside this release: tags, categorization rules/ML, live investment prices, per-user settings and reporting currency, manual exchange rates, credit-card statements, PWA/offline, bank APIs and expanded sharing for budgets/goals/assets/debts/bills. No global active-household switcher is implemented.

# 2. Features

Scope and priorities, grouped by release. Related: [[3. User flows]] · [[5. Data model]] · [[6. API surface]].

> [!info] **Build order ≠ release tier.** The MVP below is built **ledger-first**: the core ledger ships in [[11. Milestones & tasks#M1 — Core ledger|M1]] on localhost, and the auth spine follows in [[11. Milestones & tasks#M2 — Auth & hardening|M2]] before any remote exposure ([[9. Open questions & decisions|D51]]).

## Must-have (MVP)
| Feature | Description | Notes |
| ------- | ----------- | ----- |
| Transaction CRUD | Create, read, update, and delete transactions, covering both income and expenses | Core action — keep entry fast; built first ([[5. Data model#Transaction]]) |
| Categories CRUD | Create and manage categories used to tag transactions (e.g. food, rent, salary) | Ship with sensible defaults; let users add their own ([[5. Data model#Category]]) |
| Accounts & total balance | Track multiple accounts (e.g. bank accounts, cash, savings) and show the combined total balance | Each transaction belongs to an account ([[5. Data model#Account]]) |
| Dashboard | Show current balance plus this month's income vs. expenses | Lives on the home screen; period in the configured timezone ([[9. Open questions & decisions\|D56]]) |
| Localization (EN + LT) | English UI from the first release with i18n structure in place; Lithuanian translations follow | Built in from the start, not retrofitted; `lt` strings may lag EN ([[8. Non-functional requirements#Localization (i18n)]], [[9. Open questions & decisions\|D21]]) |
| Authentication & authorization | Log in / out with **"remember me"** and **optional 2FA**; each user sees only their own data | Built in **M2**, after the ledger ([[9. Open questions & decisions\|D51]]); needed before remote exposure. 2FA optional ([[9. Open questions & decisions\|D52]]); email verification/reset deferred ([[9. Open questions & decisions\|D53]]) |
| User management (admin) | An **admin** creates users (password set directly) and assigns roles; users manage their own profile | No open self-registration; email invites deferred ([[9. Open questions & decisions\|D35]], [[9. Open questions & decisions\|D53]]) |

## Should-have (v1.1)
| Feature | Description | Notes |
| ------- | ----------- | ----- |
| Account transfers | Move money between your own accounts without it counting as income or expense | Dedicated `Transfer`, nets to zero ([[5. Data model#Transfer (v1.1)]]) |
| Split transactions | Divide one transaction across categories (e.g. a supermarket trip into food / clothes / cleaning) | Optional line items; total = sum of lines ([[5. Data model#TransactionLine]], [[9. Open questions & decisions\|D46]]) |
| Search & filter | Find transactions by category, date range, amount, or account | Filter state in type-safe URL search params ([[9. Open questions & decisions\|D29]]) |
| Spending charts | Visual breakdown of spending by category and over time | e.g. category pie + monthly trend line; excludes transfers |

## Should-have (v1.2)
| Feature | Description | Notes |
| ------- | ----------- | ----- |
| Swedbank CSV import | Import transactions from a Swedbank CSV export via file upload, mapping columns to amount, date, and description | User downloads the CSV from their bank; app parses and adds the transactions ([[3. User flows#Flow: Import a Swedbank CSV]]) |
| Budgets | Set a maximum monthly spend per category and track actual spending against that limit | Warn or highlight when a category is near or over its limit ([[5. Data model#Budget (v1.2)]]) |
| Goals | Set a savings target to work toward (e.g. "€2,000 emergency fund") and track progress over time | Saving toward a number, as opposed to capping spend like budgets ([[5. Data model#Goal (v1.2)]]) |
| Net worth tracking | Combine all accounts, assets, and debts into one figure over time | Assets + debts + snapshots → [[5. Data model#Net worth (v1.2)]] |

## Nice-to-have (later)
| Feature | Description | Notes |
| ------- | ----------- | ----- |
| Households & sharing | Share chosen accounts (and their transactions) with a household you belong to; everyone in it can view + edit, while personal accounts stay private | **Deferred from v1.1** ([[9. Open questions & decisions\|D50]]). MVP keeps `UserId` only; adding `Scope`/`HouseholdId` + household tables later is an additive migration ([[5. Data model#Ownership]], [[11. Milestones & tasks#M6 — Households & sharing]]) |
| Stock / investment tracking | Track holdings and portfolio value alongside cash accounts | Needs live price data — adds an external dependency |
| AI spending analysis | Surface patterns, anomalies, and tailored suggestions from transaction history | Strongest once you have months of real data |
| Yearly review | An end-of-year summary of income, spending by category, and trends | "Year in review" style recap |
| Export | Download transactions as CSV / PDF | Mirror of the import; eases trust and backups |
| Multi-currency | Record transactions in different currencies with conversion | Adds FX rates + a base currency (the `Money` type is already currency-aware, [[9. Open questions & decisions\|D40]]) |
| Recurring bills & reminders | Track subscriptions/bills on a cadence: **fixed** price (e.g. Spotify, editable when it changes) or **variable** (reminder on the due date, enter the amount when it arrives) | No auto-posting — surfaces a reminder the user confirms ([[5. Data model#RecurringBill]], [[9. Open questions & decisions\|D13]]) |
| Notifications | In-app notification center for reminders (e.g. a bill is due); mark-as-read | In-app primary, **email channel** too (SMTP set up early) ([[5. Data model#Notification]], [[9. Open questions & decisions\|D14]]) |
| Debt / loan tracking | Track loans and payoff progress (e.g. mortgage, car) | Extends the v1.2 `Debt` entity with payoff progress ([[5. Data model#Debt]]) |
| Credit cards | Track credit-card balances and statements | Deferred to the **far future** ([[9. Open questions & decisions\|D43]]) |
| Tags | Free-form labels on transactions, separate from categories | e.g. "vacation-2026", "reimbursable" |
| Reports & custom date ranges | Build a report for any period, not just the current month | Powers tax prep and reviews |
| Dark mode / themes | Visual preference toggle | Low effort, high satisfaction |
| Mobile PWA / offline | Installable app that works without a connection | For easier control — to be expanded later |
| Automatic transaction categorization via rules + ML | Auto-add categories (and tags) using user-defined rules and, later, an ML model | Planned direction, post-MVP; manual categorization for v1 ([[9. Open questions & decisions\|D11]]) |

## Explicitly out of scope
*Things deliberately NOT being built, to avoid scope creep.*
- Direct bank API / open-banking integration — CSV import only; no live account syncing
- Real-time transaction sync or webhooks from banks
- Multi-bank support — Swedbank CSV format only for now
- Automatic categorization for MVP — manual category, with an "Uncategorized" bucket (revisit later, see Nice-to-have above)
- Bill payment or money movement — the app records money, it never moves it
- Tax filing or tax-report generation
- Cryptocurrency tracking
- Receipt OCR / scanning
- Shared/collaborative editing in real time
- SMS / push notifications — in-app and email notifications are supported ([[9. Open questions & decisions|D14]]); SMS and push are not planned
- Open self-registration — accounts are created by an admin ([[9. Open questions & decisions|D35]])
